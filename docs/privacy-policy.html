RowTool Privacy Policy

Last updated: 9 August 2026

RowTool is a Finnvek application designed to work completely offline. RowTool does not collect or transmit personal data.

Information stored on your device

Project names, row or round counts, targets, repeat settings, archive state, and application preferences are stored locally in RowTool's private application storage. Finnvek cannot access this information.

Export and import

Backup export and import are initiated only by you. When you export data, RowTool writes a backup to the location you choose with Android's system document picker. When you import data, RowTool reads only the backup file you select. RowTool does not upload or transmit backup files.

An exported backup is stored outside RowTool's private application storage. You are responsible for protecting or deleting exported backup files.

Advertising, analytics, and accounts

RowTool contains no advertising or analytics SDK. It does not create user accounts and does not use cloud storage.

Uninstalling RowTool

Uninstalling RowTool removes its local application data through the Android platform. A backup that you previously exported remains in the location you selected unless you delete it separately.

Contact

For privacy questions, use the Finnvek contact information shown on RowTool's Google Play listing.
